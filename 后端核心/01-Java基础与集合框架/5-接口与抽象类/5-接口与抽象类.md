# 5- 接口与抽象类

## 一、学什么

> 1. 接口与抽象类两者的语法差异（字段、构造器、方法、继承数量等）
> 2. 设计语义（is-a关系与能力契约）



## 二、做什么

### 2.1 知识学习

读《Java核心技术 卷1》第 6 章"接口、lambda 表达式与内部类"的接口部分 + JavaGuide "接口和抽象类有什么区别"。

**1. 接口**
一组行为的契约/规范
**(1) 接口的特点**

+  不能用 `new` 创建接口实例对象，但是可以声明接口引用变量，指向实现类对象，实现多态

  ```java
  //和多态的实现差不多
  interface Stand {
      void say();
  }
  // 实现类
  class StandImpl implements Stand{
      @Override
      public void say() {
          System.out.println("实现类的say");
      }
  }
  
  public class Test {
      public static void main(String[] args) {
          // ✅ 接口引用，指向实现类实例（多态写法）
          Stand s = new StandImpl();
          s.say();
      }
  }
  ```

+ 没有构造器

+ 不能包含实例代码块、静态代码块

  ```java
  //实例代码块
  class Test{
  	//每次new都会执行一次
      {
          System.out.println("实例代码块");
      }
      public Test(){
          System.out.println("构造器");
      }
  }
  
  //静态代码块
  class Test{
  	//只会执行一次
      static {
          System.out.println("静态代码块");
      }
  }
  
  //执行顺序： 静态代码块 -> 实例代码块 -> 构造函数
  ```

+ 一个类可以实现多个接口

+ 接口可以多继承

+ 核心用途：定义能力、行为

**(2) 语法**

```java
//接口
interface 接口名 {
    // 常量：默认 public static final
    String NAME = "test";

    // Java7：抽象方法，默认 public abstract
    void say();

    // Java8：默认方法（带实现）
    default void hello() {
        System.out.println("default method");
    }

    // Java8：静态方法，属于接口本身
    static void staticFunc() {
        System.out.println("interface static");
    }

    // Java9：私有方法，接口内部代码复用
    private void privateFunc(){}
}

//实现 implements
class A implements 接口名1, 接口名2 {
    // 必须重写所有抽象方法，除非A本身是abstract类
    @Override
    public void say() {}
}
```

**(3) 接口成员规则**

+ 变量
  只能是常量，隐式 `public static final`，定义时必须赋值，不能修改。没有实例变量，不能保存对象状态。
+ 抽象方法(abstract)
  隐式 `public abstract`，没有方法体
+ 默认方法(default)
  实例方法，带方法体；实现类可以直接使用，也可以重写
  **冲突规则：**1.如果父类有同名方法，父类方法优先级 > 接口default方法。2.类同时实现多个接口，出现同名同参数default方法要手动修改
+ 静态方法(static)
  属于接口本身，不能被实现类继承，只能 `接口名.静态方法()` 调用
  这和类不一样，类可以继承
+ 私有方法(private)
  其他的方法都是public
  只能在接口内部使用，给default方法复用代码，外部无法访问

**2. 抽象类**
一类事物的通用模板，提取多个子类共有的属性和行为。用 `abstract` 修饰。
**(1) 抽象类的特点**

+ 不能直接 new 创建抽象类对象。可以定义抽象类引用，指向子类对象实现多态。
+ 可以拥有实例字段，保存对象属性状态
+ 可以有构造器、代码块
+  只能单继承

**(2) 语法**

```java
abstract class Animal {
    // 实例成员变量，可以保存对象状态（接口没有这个！）
    String name;

    // 构造方法！抽象类有构造器，供子类super()调用，不能用来new抽象类对象
    public Animal(String name) {
        this.name = name;
    }

    // 抽象方法：abstract修饰，没有方法体，子类必须实现
    public abstract void shout();

    // 普通实例方法，有实现，子类直接继承复用
    public void sleep() {
        System.out.println("睡觉");
    }

    // 静态方法，属于抽象类本身，可以被子类继承
    public static void testStatic(){}
}

//子类
class Dog extends Animal {
    public Dog(String name) {
        super(name);
    }
    // 必须实现父类所有抽象方法，否则Dog也要声明为abstract
    @Override
    public void shout() {
        System.out.println("汪汪");
    }
}
```

**(3) 抽象类成员规则**

+ 成员变量
  可以是实例变量、静态变量；权限可以是 public / protected / private。可以存储对象状态。
+ 构造方法
  有构造器，但不能直接 `new` 抽象类。构造器作用：子类实例化时初始化抽象类中的成员。
+ 抽象方法
  有抽象方法的类一定是抽象类。抽象类不一定有抽象方法（可以全部是普通方法）。

### 2.2 实现

写一个对比工程：
抽象类 `Pay`（含 `balance` 字段、构造器、普通方法 `checkBalance()`、抽象方法 `pay()`）
接口 `Payable`（含 `default` 方法 `log()`、`static` 方法 `tip()`、常量 `MAX_AMOUNT`）
分别由 `Alipay`/`WechatPay` 实现，跑通并体会各自适用场景。

**接口**：多个无关的类，需要拥有同一个行为能力，想要多态和解耦。
**抽象类**：多个子类属于同一类事物，存在大量共享的属性和代码，需要复用状态。

### 2.3 接口与抽象类的差异

继承——抽象类单继承、接口多实现；
成员——抽象类可有字段/构造器/私有方法，接口字段恒为 `public static final`；
方法——抽象类可有普通方法，接口 JDK8 后可 default/static、JDK9 后可 private；
语义——抽象类是"是什么"，接口是"能做什么"

### 2.4 接口的default方法

为了给已有接口平滑增加方法而不破坏所有实现类



## 三、实践

**1. 写出接口与抽象类的差异**
1. 语义上：抽象类代表 is-a，是一类事物的模板；接口代表 can-do，是行为能力契约。
2. 继承：类只能单继承抽象类；但可以多实现接口，接口本身支持多继承。
3. 成员变量：抽象类可以有实例变量保存对象状态；接口只能有 public static final 常量。
4. 构造器：抽象类有构造方法供子类调用；接口没有构造器。
5. 方法：抽象类方法权限任意，可以包含抽象、普通、静态方法；Java8 之后接口新增 default、static 方法，Java9 新增 private 方法，接口的 default、抽象、static 方法只能是 public。
6. 静态方法：抽象类静态方法可以被子类继承；接口静态方法不能被实现类继承。

**2. 设计一个抽象类+接口组合的例子**

```java
// 接口：定义【发声能力】，代表一种行为契约
public interface Speakable {
    // 抽象方法：能发出声音
    void speak();

    // default 默认方法：通用行为
    default void welcome() {
        System.out.println("我是一个会发声的动物");
    }
}

// 抽象类：动物模板，is-a关系，抽取公共属性
public abstract class Animal {
    // 公共字段，子类可以直接访问
    protected String name;

    // 抽象类有构造器，子类调用super初始化name
    public Animal(String name) {
        this.name = name;
    }

    // 普通实例方法，所有动物复用
    public void sleep() {
        System.out.println(name + "正在睡觉");
    }

    // 抽象方法：交给子类实现
    public abstract void eat();
}

// 子类：继承抽象类Animal，同时实现接口Speakable
public class Dog extends Animal implements Speakable {

    // 子类构造器，调用父抽象类构造方法
    public Dog(String name) {
        super(name);
    }

    // 实现抽象类的抽象方法 eat
    @Override
    public void eat() {
        System.out.println(name + "啃骨头");
    }

    // 实现接口Speakable的抽象方法 speak
    @Override
    public void speak() {
        System.out.println(name + "：汪汪汪");
    }
}

// 测试类
public class Test {
    public static void main(String[] args) {
        // 多态1：抽象类引用指向子类对象
        Animal animal = new Dog("旺财");
        animal.eat();
        animal.sleep();

        // 多态2：接口引用指向实现类对象
        Speakable speak = new Dog("旺财");
        speak.speak();
        speak.welcome();
    }
}
```



## 四、问题

**1. 抽象类和接口的区别**
1. 语义上：抽象类代表 is-a，是一类事物的模板；接口代表 can-do，是行为能力契约。
2. 继承：类只能单继承抽象类；但可以多实现接口，接口本身支持多继承。
3. 成员变量：抽象类可以有实例变量保存对象状态；接口只能有 public static final 常量。
4. 构造器：抽象类有构造方法供子类调用；接口没有构造器。
5. 方法：抽象类方法权限任意，可以包含抽象、普通、静态方法；Java8 之后接口新增 default、static 方法，Java9 新增 private 方法，接口的 default、抽象、static 方法只能是 public。
6. 静态方法：抽象类静态方法可以被子类继承；接口静态方法不能被实现类继承。

**2. 什么时候用抽象类，什么时候用接口**

**接口**：多个无关的类，需要拥有同一个行为能力，想要多态和解耦。
**抽象类**：多个子类属于同一类事物，存在大量共享的属性和代码，需要复用状态。

**3. 接口能实例化吗**
不能

**4. 为什么lambda可以赋给接口**
Lambda 表达式可以赋值给接口，前提是这个接口是**函数式接口**：接口中有且仅有一个抽象方法。
Lambda 本质是该接口唯一抽象方法的实现简写。JVM 会自动生成实现该接口的类，把 lambda 代码放入抽象方法，因此可以把 lambda 赋值给这个接口类型的引用变量。default、static 方法不影响函数式接口的判定。
