**1. 封装**
隐藏内部细节，对外暴露安全访问接口
**(1) 实现**
用 `private` 私有化成员变量，提供 `get/set` 方法，可在 `set` 做数据校验

```java
// Person.java
package com.morning;

public class Person {
    private int age;

    public int getAge(){
        return age;
    }

    public void setAge(int age){
        if(age > 0 && age <= 150){
            this.age = age;
        }else{
            System.out.println("年龄不合法！");
        }
    }
}

// PersonTest.java
```

**(2) 访问权限**
从宽到窄 public > protected > 缺省(同包) > private 

| 修饰符      | 本类 | 同包 | 不同包子类 | 不同包无关类 |
| ----------- | ---- | ---- | ---------- | ------------ |
| public      | ✅    | ✅    | ✅          | ✅            |
| protected   | ✅    | ✅    | ✅          | ❌            |
| 缺省 (同包) | ✅    | ✅    | ❌          | ❌            |
| private     | ✅    | ❌    | ❌          | ❌            |

**(3) 思想**
合理隐藏，合理暴露，保障数据安全，降低耦合

**2. 继承**
子类复用父类代码
is-a关系，关键词 `extends`
**(1) 注意点**
java类只能单继承
**(2) super**
访问父类成员，super()调用父类构造器，必须放在子类构造器的第一行
**(3) 方法重写override**
父子类之间，方法名、参数列表一致。子类的访问权限不能低于父类的访问权限
**4. final**
final类不能被继承，final方法不能重写，final变量只能赋值一次

**3. 多态**
对同一个行为，不同对象有不同的实现
编译看左边，运行看右边
**(1) 三要素**
继承、方法重写、父类引用指向子类的对象

```java
Animal a = new Dog();
```

**(2) 成员方法**
编译看父类，运行执行子类重写方法（动态重写）
**(3) 成员变量**
没有多态，编译运行都看左边引用类型
**(4) 转型**
**向上转型：**自动，只能调用父类方法，无法访问子类独有方法
**向下转型：**强制转换，用` instanceof`进行预判

**Java 多态完整示例**
<a name="point3" href="#point3-back" style="color:sky;text-decoration:none">返回</a>

核心口诀：**编译看左边，运行看右边** 三要素：**继承 + 方法重写 + 父类引用指向子类对象**

```
// 父类
class Animal {
    String name = "动物";

    public void eat() {
        System.out.println("动物吃东西");
    }
}

// 子类Dog继承Animal
class Dog extends Animal {
    // 子类同名成员变量：成员变量没有多态
    String name = "小狗";

    // 方法重写
    @Override
    public void eat() {
        System.out.println("小狗啃骨头");
    }

    // 子类独有的方法
    public void watchHouse() {
        System.out.println("小狗看家");
    }
}

// 子类Cat继承Animal
class Cat extends Animal {
    String name = "小猫";

    @Override
    public void eat() {
        System.out.println("小猫吃鱼");
    }

    // 子类独有方法
    public void catchMouse() {
        System.out.println("小猫抓老鼠");
    }
}

public class TestPolymorphic {
    public static void main(String[] args) {
        // ========== 向上转型：父类引用指向子类对象，自动转换 ==========
        Animal a1 = new Dog();
        Animal a2 = new Cat();

        // ✅成员方法：编译看左边(Animal有没有eat)，运行看右边(Dog/Cat的eat)
        a1.eat(); // 输出：小狗啃骨头
        a2.eat(); // 输出：小猫吃鱼

        // ❗成员变量：没有多态！编译运行都看左边引用类型Animal
        System.out.println(a1.name); // 输出：动物，不是小狗！
        System.out.println(a2.name); // 输出：动物

        // a1.watchHouse(); // 编译报错！向上转型后，不能直接调用子类独有方法

        // ========== 向下转型：强制类型转换，使用instanceof预判 ==========
        if (a1 instanceof Dog) {
            Dog dog = (Dog) a1; // 向下转型
            dog.watchHouse(); // 可以调用子类独有方法：小狗看家
        }

        if (a2 instanceof Cat) {
            Cat cat = (Cat) a2;
            cat.catchMouse(); // 小猫抓老鼠
        }

        // 错误示范：类型不匹配，会抛出ClassCastException
        // Dog dog2 = (Dog) a2; // a2实际是Cat，强转会报错！所以必须用instanceof判断
    }
}
```

```
public static void feed(Animal animal){
    animal.eat();
}

feed(new Dog());
feed(new Cat());
```

**3. 构造方法为什么不能重写**
构造方法名必须与当前类名完全相同。子类和父类类名不同，构造器名字天然不一样，不满足重写 “方法名相同” 的前提。
