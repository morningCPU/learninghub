## 062 N 皇后

### 一、题目

[N 皇后](https://leetcode.cn/problems/n-queens/)

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

**n 皇后问题** 研究的是如何将 `n` 个皇后放置在 `n×n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n` ，返回所有不同的 **n 皇后问题** 的解决方案。

每一种解法包含一个不同的 **n 皇后问题** 的棋子放置方案，该方案中 `'Q'` 和 `'.'` 分别代表了皇后和空位。

---

**示例 1：**

```
输入：n = 4
输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
解释：如上图所示，4 皇后问题存在两个不同的解法。
```

**示例 2：**

```
输入：n = 1
输出：[["Q"]]
```

---

**提示：**

- `1 <= n <= 9`



### 二、解答

```cpp
class Solution {
public:
    vector<vector<string>> res;

    void dfs(int n,int i,vector<string>& board,vector<bool>& col,vector<bool>& dig1,vector<bool>& dig2){
        if(i == n){
            res.push_back(board);
            return;
        }
        for(int j = 0;j<n;++j){
            //对角线的位置
            int d1 = i - j + n - 1;
            int d2 = i + j;
            if(!col[j] && !dig1[d1] && !dig2[d2]){
                col[j] = true;
                dig1[d1] = true;
                dig2[d2] = true;
                board[i][j] = 'Q';
                dfs(n,i+1,board,col,dig1,dig2);
                col[j] = false;
                dig1[d1] = false;
                dig2[d2] = false;
                board[i][j] = '.';
            }
        }
    }

    vector<vector<string>> solveNQueens(int n) {
        vector<string> board(n,string(n,'.'));
        vector<bool> col(n,false);
        vector<bool> dig1(n*2-1,false);
        vector<bool> dig2(n*2-1,false);
        dfs(n,0,board,col,dig1,dig2);
        return res;
    }
};
```
