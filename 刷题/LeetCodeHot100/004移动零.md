## 004 移动零

### 一、题目

给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。

**请注意** ，必须在不复制数组的情况下原地对数组进行操作。

---

**示例 1:**

```
输入: nums = [0,1,0,3,12]
输出: [1,3,12,0,0]
```

**示例 2:**

```
输入: nums = [0]
输出: [0]
```

---

**提示**:

- `1 <= nums.length <= 104`
- `-231 <= nums[i] <= 231 - 1`

---

**进阶：**你能尽量减少完成的操作次数吗？



### 二、解答

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        // 使用双指针
        int i = 0,j = 0;
        int n = nums.size();
        while(j<n){
            // 不是0就换到前面，这自然就把0放到后面了
            if(nums[j]!=0){
                //因为j在i后面，而j后面的都是排好了的，所以i交换过来的一定不是0，j++
                //这里if里面没有j++，因为这个if是否成立的两种情况都需要j++，所以就放外面了
                swap(nums[i],nums[j]);
                i++;
            }
            j++;
        }
    }
};
```



### 三、思路

使用双指针，将不为0的放到前面
