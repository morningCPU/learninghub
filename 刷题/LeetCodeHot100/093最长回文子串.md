## 093 最长回文子串

### 一、题目

[最长回文子串](https://leetcode.cn/problems/longest-palindromic-substring/)

给你一个字符串 `s`，找到 `s` 中最长的 回文 子串。

---

**示例 1：**

```
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。
```

**示例 2：**

```
输入：s = "cbbd"
输出："bb"
```

---

**提示：**

- `1 <= s.length <= 1000`
- `s` 仅由数字和英文字母组成



### 二、解答

```cpp
class Solution {
public:
    string longestPalindrome(string s) {
        int n = s.size();
        int resl = 0,resr = 0;
        int l=0,r=0;
        // 统一奇数和偶数的情况
        for(int i = 0;i<n*2-1;++i){
            l = i/2;
            r = (i+1)/2;
            while(l>=0&&r<n&&s[l]==s[r]){
                l--,r++;
            }
            l++,r--;
            if(r-l>resr-resl){
                resl = l;
                resr = r;
            }
        }
        return s.substr(resl,resr-resl+1);
    }
};
```



### 三、思路

`for(int i = 0;i<n*2-1;++i)`

`l = i/2;`

` r = (i+1)/2;` 

使用这个统一了奇数和偶数的情况
