## 012 最小覆盖子串

### 一、题目

[最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/)

给定两个字符串 `s` 和 `t`，长度分别是 `m` 和 `n`，返回 s 中的 **最短窗口 子串**，使得该子串包含 `t` 中的每一个字符（**包括重复字符**）。如果没有这样的子串，返回空字符串 `""`。

测试用例保证答案唯一。

---

**示例 1：**

```
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。
```

**示例 2：**

```
输入：s = "a", t = "a"
输出："a"
解释：整个字符串 s 是最小覆盖子串。
```

**示例 3:**

```
输入: s = "a", t = "aa"
输出: ""
解释: t 中两个字符 'a' 均应包含在 s 的子串中，
因此没有符合条件的子字符串，返回空字符串。
```

---

**提示：**

- `m == s.length`
- `n == t.length`
- `1 <= m, n <= 105`
- `s` 和 `t` 由英文字母组成

---

###  二、解答

```cpp
class Solution {
public:
    string minWindow(string s, string t) {
        //两个计数，一个计数量，一个计种类
        vector<int> cnt(128,0);
        int kinds = 0;
        for(const char& c : t){
            //在数量为0的时候是转折点进行种类数目的跟新
            if(cnt[c] == 0)kinds++;
            cnt[c]++;
        }
        int l = 0;
        int n = s.size();
        int resl = -1,resr = n;
        int cur_kinds = 0;
        for(int r = 0;r<n;++r){
            char c = s[r];
            cnt[c]--;
            if(cnt[c] == 0)cur_kinds++;
            while(cur_kinds == kinds){
                if(resr - resl > r - l){
                    resl = l;
                    resr = r;
                }
                char c = s[l];
                cnt[c]++;
                l++;
                if(cnt[c] > 0)cur_kinds--;
            }
        }
        return resl == -1 ? "" : s.substr(resl,resr-resl+1);
    }
};
```
