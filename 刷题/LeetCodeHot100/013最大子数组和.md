## 013 最大子数组和

### 一、题目

[最大子数组和](https://leetcode.cn/problems/maximum-subarray/)

给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**子数组**是数组中的一个连续部分。

---

**示例 1：**

```
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6 。
```

**示例 2：**

```
输入：nums = [1]
输出：1
```

**示例 3：**

```
输入：nums = [5,4,-1,7,8]
输出：23
```

---

**提示：**

- `1 <= nums.length <= 105`
- `-104 <= nums[i] <= 104`

---

**进阶：**如果你已经实现复杂度为 `O(n)` 的解法，尝试使用更为精妙的 **分治法** 求解。



### 二、解答

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        // s是一个前缀和
        int s = 0;
        int res = INT_MIN;
        for(const int& i : nums){
            //前面的子串的和<=0,那么加上来并不会让后面的变大，没有益处，所以重新开始
            if(s <= 0){
                s = i;
            }else{
                //否则接着
                s += i;
            }
            res = max(res,s);
        }
        return res;
    }
};
```



### 三、思路

使用前缀和，看前面的子串的贡献是否是正的
