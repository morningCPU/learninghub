## 047 从前序与中序遍历序列构造二叉树

### 一、题目

[从前序与中序遍历序列构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)

给定两个整数数组 `preorder` 和 `inorder` ，其中 `preorder` 是二叉树的**先序遍历**， `inorder` 是同一棵树的**中序遍历**，请构造二叉树并返回其根节点。

---

**示例 1:**

```
输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出: [3,9,20,null,null,15,7]
```

**示例 2:**

```
输入: preorder = [-1], inorder = [-1]
输出: [-1]
```

---

**提示:**

- `1 <= preorder.length <= 3000`
- `inorder.length == preorder.length`
- `-3000 <= preorder[i], inorder[i] <= 3000`
- `preorder` 和 `inorder` 均 **无重复** 元素
- `inorder` 均出现在 `preorder`
- `preorder` **保证** 为二叉树的前序遍历序列
- `inorder` **保证** 为二叉树的中序遍历序列



### 二、解题

```cpp
class Solution {
public:
    // 使用map从而在知道前序节点的情况下可以知道这个节点在后序的哪里
    // 这个是因为在中序中是不知道中点是在哪里的，而前序的中点就是第一个
    // 但是前序又少了一个信息，不知道左右子树的大小（主要是左子树，知道左子树大小右子树就知道了）
    // 所有需要通过前序找到中点，通过map知道中点在中序的位置，从而可以在中序中求得左子树的大小
    unordered_map<int,int> mp;

    TreeNode* build(vector<int>& preorder,vector<int>& inorder,int preorder_left,int preorder_right,int inorder_left){
        //这个right的作用主要就是截止作用，左右子树知道一个就可以了
        if(preorder_left > preorder_right)return nullptr;
        //得到中点
        int preorder_mid = preorder_left;
        //中点在中序中的位置
        int inorder_mid = mp[preorder[preorder_mid]];
        //左子树的大小
        int size = inorder_mid - inorder_left;
        //构造
        TreeNode* node = new TreeNode(preorder[preorder_mid]);
        node->left = build(preorder,inorder,preorder_mid+1,preorder_mid+size,inorder_left);
        node->right = build(preorder,inorder,preorder_mid+size+1,preorder_right,inorder_mid+1);
        return node;
    }

    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        int n = inorder.size();
        for(int i = 0;i<n;++i){
            mp[inorder[i]] = i;
        }
        return build(preorder,inorder,0,n-1,0);
    }
};
```



### 三、思路

使用map从而在知道前序节点的情况下可以知道这个节点在后序的哪里
这个是因为在中序中是不知道中点是在哪里的，而前序的中点就是第一个
但是前序又少了一个信息，不知道左右子树的大小（主要是左子树，知道左子树大小右子树就知道了）
所有需要通过前序找到中点，通过map知道中点在中序的位置，从而可以在中序中求得左子树的大小
