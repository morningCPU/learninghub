## 003 最长连续序列

### 一、题目

[最长连续序列](https://leetcode.cn/problems/longest-consecutive-sequence/description/)

给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

请你设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

---

**示例 1：**

```
输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]。它的长度为 4。
```

**示例 2：**

```
输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9
```

**示例 3：**

```
输入：nums = [1,0,1,2]
输出：3
```

---

**提示：**

- `0 <= nums.length <= 105`
- `-109 <= nums[i] <= 109`



### 二、解答

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        // 使用集合的作用是为了快速查找一个数是否存在
        unordered_set<int> set(nums.begin(),nums.end());
        int res = 0;
        for(const int& i : nums){
            //这里是剪枝1：因为如果i-1存在的话，下面的j会已经进行了扩展，所以就不需要再进行处理了
            if(set.count(i-1))continue;
            int j = i + 1;
            //就是这里
            while(set.count(j))j++;
            res = max(res,j-i);
            //剪枝2：如果j*2>n的话那这个数组大小不够，==n的话结果一样
            if(j*2 >= n)break;
        }
        return res;
    }
};
```

使用一个set进行快速判断一个数字/前后数字是否存在
