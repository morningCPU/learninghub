## 068 寻找两个正序数组的中位数

### 一、题目

[寻找两个正序数组的中位数](https://leetcode.cn/problems/median-of-two-sorted-arrays/)

给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数** 。

算法的时间复杂度应该为 `O(log (m+n))` 。

---

**示例 1：**

```
输入：nums1 = [1,3], nums2 = [2]
输出：2.00000
解释：合并数组 = [1,2,3] ，中位数 2
```

**示例 2：**

```
输入：nums1 = [1,2], nums2 = [3,4]
输出：2.50000
解释：合并数组 = [1,2,3,4] ，中位数 (2 + 3) / 2 = 2.5
```

---

**提示：**

- `nums1.length == m`
- `nums2.length == n`
- `0 <= m <= 1000`
- `0 <= n <= 1000`
- `1 <= m + n <= 2000`
- `-106 <= nums1[i], nums2[i] <= 106`



### 二、解答

```cpp
class Solution {
public:
    double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2) {
        int len1 = nums1.size(),len2 = nums2.size();
        // len1 > len2 防止j<0
        if(len1 > len2)return findMedianSortedArrays(nums2,nums1);
        // 这个0，len1指的是在num1中取多少个
        int l = 0,r = len1;
        double res = 0;
        while(l<=r){
            //i指的是在nums1中左边取的数量
            int i = (l+r)/2;
            //j指的是在nums2中左边取的数量
            int j = (len1 + len2 + 1)/2 - i;
            if(i-1>=0 && j<len2 && nums1[i-1]>nums2[j]){
                r = i - 1;
            }else if(j-1>=0 && i<len1 && nums2[j-1]>nums1[i]){
                l = i + 1;
            }else{
                if(i==0)res = nums2[j-1];
                else if(j==0)res = nums1[i-1];
                else res = max(nums1[i-1],nums2[j-1]);
                if((len1+len2)%2==1)return res;
                if(i==len1)res += nums2[j];
                else if(j==len2)res += nums1[i];
                else res += min(nums1[i],nums2[j]);
                res/=2;
                return res;
            }
        }
        return 0;
    }
};
```
