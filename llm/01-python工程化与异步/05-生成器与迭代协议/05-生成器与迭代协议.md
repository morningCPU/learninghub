## 二、基础知识

### 2.1 迭代协议

**(1) 两个魔法方法**
是所有for循环,`in`,`next()`的底层规则
**`__iter()`**
返回一个迭代器对象
`__next__`
迭代器方法，返回下一个元素，没有元素的时候抛出`StopIteration`

**(2) 生成器**
语法糖自动帮忙实现迭代协议的迭代器

**(3) 生成器的两种写法**
**1.生成器函数**
函数内部出现 `yield` 关键字，调用函数不会立刻执行代码，而是返回一个生成器迭代器对象
**2.生成器表达式**
`(x for x in range(100))`
注意对比列表推导式
`[x for x in range(100)]`

### 2.2 yield

暂停、恢复、状态保存

**(1) 执行流程**

```python
def gen():
    print("start")
    yield 1
    print("mid")
    yield 2
    print("end")

g = gen()       # 不打印任何东西，拿到生成器对象
next(g)         # 打印 start，返回1，停在 yield 1
next(g)         # 从暂停处继续执行，打印 mid，返回2，停在 yield2
next(g)         # 打印 end，走到函数末尾，抛出 StopIteration
```

**(2) 问题**

**1. yield 暂停时，局部变量、执行状态保存在哪里**
普通函数 return 之后栈帧销毁；生成器 yield 时挂起栈帧，对象保留在堆，下次 next 恢复帧继续跑。

**2.为什么生成器只能遍历一次**
生成器本身就是**迭代器**。迭代器的语义就是一次性消耗：`__next__` 不断推进内部状态，没有 “回退、重置指针” 的机制。

**(3) yield from**
`yield from sub_gen` 是语法糖，等价于把子生成器当成迭代器
