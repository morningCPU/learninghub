# 01-类型注解与静态检查  
  
## 作用  
  
**1.提高效率，提供索引**  
改一个函数的返回值，mypy能够立即告诉所有调用方那里会崩，而不需要跑一遍完整的测试  
**2.比注释和文档更加准确直接**  
**3.能够进行安全重构**  
mypy会引导走完所有需要修改的路径  
  
## 一、学什么  
  
> 1. mypy类型系统，Any/Protocol/TypeVar/Literal/ocerload  
> 2. Type hints cheat sheet  
  
  
  
## 二、知识学习  
  
**1. Any**  
  
表示mypy放弃对这个变量做任何检查  
  
Any可以赋值给任意类型，任意类型也可以赋值给Any,这就是类型污染的根源，一个Any的传入会导致整个调用链都变成Any，直接让静态检查失效  
  
`Any` 和 `object` 要注意区分，Any允许任何操作，object只允许对象操作  
  
能不用Any就不用，临时替代优先使用Protocol或者泛型  
  
**2. TypeVar**  
  
泛型，用来保证输入输出是同一个类型  
  
```python  
from typing import TypeVar  
  
T = TypeVar("T") #需要一个name  
  
def identity(x:T)->T:  
    return x  
```  
  
可以加入边界  
  
```python  
T = TypeVar("T",str,int) #使用其中一个  
U = TypeVar("U",bound=float) #定义上界  
```  
  
**3. Literal**  
  
限定取值，不只是限定类型  
  
```python  
from typing import Literal  
  
Mode = Literal["read","write"]  
def open_file(mode : Mode):  
    ...  
```  
  
> 面试题  
> Literal["read"] 是 str 的子类型，但是不等于str  
  
**4. @overload**  
  
同一个函数，多组签名  
  
```python  
from typing import overload  
  
@overload  
def parse(s:str)->str: ...  
@overload  
def parse(s:int)->int: ...  
def parse(s):  
	return s  
```  
  
只用于静态检查，运行时完全忽略，真正的函数写在最后，不带装饰器  
前面没有实现，用 `...` 占位  
从上到下依次匹配  
  
**5. Protocol**  
  
结构化子类型，鸭子类型  
  
```python  
from typing import Protocol  
  
# 对一个对象进行限制  
# 这个对象要有 name:str 属性  
class HasName(Protocol):  
	name: str  
          
def greet(x:HasNmae):  
    print(x.name)  
```  
  
**6. 自己的总结**  
  
Any不进行检查  
TypeVar限定类型  
Literal限定取值  
@overload提供多个选择  
Protocol限定对象属性  
  
  
  
## 三、实践  
  
拿一个300+行旧脚本，`mypy --strict`，分类报错，修复，最后接入pre-commit，src目录生效，0 error  
  
**需要修改的代码：**  
  
```python  
"""一个典型的没有类型注解的旧脚本。"""  
  
import json  
import requests  
  
  
def load_config(path):  
    """加载配置文件。"""  
    with open(path) as f:  
        return json.load(f)  
  
  
def fetch_data(url):  
    """从 API 获取数据。"""  
    response = requests.get(url)  
    return response.json()  
  
  
def calculate_total(items):  
    """计算总价。有 bug：没处理空列表。"""  
    total = 0  
    for item in items:  
        total += item["price"] * item["quantity"]  
    return total  
  
  
def process_order(order_id, config):  
    """处理订单。返回类型不一致。"""  
    if not config.get("enabled"):  
        return None  # 这里返回 None，但声明了 int（修复时会遇到）  
      
    data = fetch_data(config["api_url"] + f"/orders/{order_id}")  
      
    # 空列表问题：mypy 会推导成 list[Any]  
    results = []  
    for item in data.get("items", []):  
        results.append({  
            "name": item["name"],  
            "value": item["price"] * item["quantity"]  
        })  
      
    return calculate_total(results)  
  
  
def main():  
    config = load_config("config.json")  
    result = process_order(123, config)  
    print(f"Result: {result}")  
  
  
if __name__ == "__main__":  
    main()  
```  
  
config.json  
  
```json  
{  
  "enabled": true,  
  "api_url": "https://api.example.com"  
}  
```  
  
**使用mypy运行发现问题**  
  
`mypy --strict main.py`  
  
**使用pre-commit**  
  
可以配置pre-commit在commit的时候自动执行mypy  
  
1. 安装，`pip install pre-commit`  
2. git项目安装，`pre-commit install`  
3. 写 `.pre-commit-config.json` 配置文件  
  
```json  
repos:  
  - repo: https://github.com/pre-commit/mirrors-mypy  
    rev: v1.11.2  
    hooks:  
      - id: mypy  
        files: main.py  
        args: ["--strict"]  
        additional_dependencies: [types-requests]  
```  
  
4. 然后commit就会自动执行 `mypy --strict main.py` 进行检查  
  
**使用第三方库没有对应的类型说明文件**  
  
一个 `a` 库，对应就有 `type-a`   
  
类型说明文件的后缀是 `.pyi`  
  
如果没有可以直接使用 `pip` 安装  
  
如果PyPI里面也没有，那就自己写Protocol  
  
  
  
## 四、问题  
  
**1. 项目里 Any 满天飞怎么治**  
找到源头，进行替换，使用strict，使用pre-commit防止回退  
  
**2. Protocol 和抽象基类(ABC)的区别，使用的选择**  
ABC是名义类型，必须显式继承。适合强制契约，继承体系  
Protocol是结构化鸭子类型，只看结构是否匹配。适合用于接收需要特定结构的对象。  
  
**3. 为什么 mypy 通过了运行时还会报 AttributeError**  
  
1. 看不见运行过程中的动态变化  
2. 可能使用`cast()`断言欺骗了mypy  
  
只能抓静态可推导类型的错误类型，不能保证消灭所有运行时错误
